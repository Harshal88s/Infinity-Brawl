# Infinity Brawl

Free browser fighting game: ten heroes and villains with signature specials and cinematic supers. Play vs CPU or a friend on one keyboard, on desktop or phone.

Static site: `index.html`, `style.css`, `game.js`, `assets/`. No build step.

## Deploy on Vercel

Import this repository at vercel.com/new. Framework preset **Other**, no build command, no output directory. Deploy.
